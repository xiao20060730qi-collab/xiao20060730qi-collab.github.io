## 项目简介

二十四节气不是日历上固定的农历日期，而是**太阳在黄道上的周年视运动**：太阳黄经每增加 15°，便迎来一个新的节气。时令把这件事讲清楚，也把它做得好看、好玩：

- **节气图鉴**：24 个节气逐一展开，科学解释、传统物候与现代观察并置；
- **节气日历**：任意年份精确交节时刻，支持订阅（.ics）；
- **七十二候**：从"东风解冻"到"水泽腹坚"，找到此刻的位置；
- **每日一签**：每日固定三道节气小题，答完生成成绩分享卡；
- **AI 节气问答**：先检索站内可信资料，再由大模型组织回答，正文标注来源；
- **灵感工坊**：选节气、定风格，用 AI 生成节气海报；
- **乐学节气**：看图答题与节气拼图，题目与配图均由 AI 生成；
- **账号体系**：收藏、打卡、云端作品跨设备同步（站点自建账号，与第三方平台无关）。

站内插画为 AI 生成内容，已在页脚与图注中标注；知识来源页列出全部参考资料。

## 功能一览

### 科普与工具

- 24 节气 × 3 候 × 四季的完整内容体系，全部内容可离线阅读；
- 交节时刻由历法库按北京时间精确计算，支持 1900—2100 年范围查询；
- 日历订阅：下载 `.ics` 导入系统日历，附交节前一天提醒；
- 每日一签 / 今日物候 / 距离下个节气倒计时等轻量日常入口；
- PWA：可"添加到主屏幕"，弱网下通过 Service Worker 缓存核心页面。

### AI 能力

| 能力 | 说明 |
|---|---|
| 节气问答 | 先做站内资料检索（节气、物候、来源引用），再由模型组织中文回答，正文用 `[来源 id]` 标注依据；无依据时会明确说明 |
| 海报生成 | 选定节气与风格生成节气插画海报，文字由前端排版，不依赖模型生成汉字 |
| 看图答题 | AI 依据资料出 3 道节气题并配图，提交后给出解析与评分 |
| 节气拼图 | AI 生成节气场景图，前端做拼图校验，完成后进入知识问答 |
| 账号与额度 | 注册登录后使用，每日额度、频率限制由服务端统一校验 |

AI 服务不可用或未配置密钥时，站点的百科、日历、收藏等静态功能不受影响，问答与生成会给出明确提示，**不会返回模拟内容**。

### 设计

- 以"四时有序，万物有时"为主线的新中式视觉：宣纸底色、青绿山水、节气印章；
- 全站响应式，移动端与桌面端各自优化的导航、卡片与阅读体验；
- 深色模式自适应（跟随系统），打印时隐藏交互元素；
- 可访问性：跳转正文链接、语义化标题层级、`aria` 标注、键盘可操作。

## 关于 AI 功能

- 模型密钥只存放在服务端环境变量中，**前端代码不包含任何密钥**；
- 问答与生成按账号统计每日额度，服务端做全球日额度与频率限制；
- 模型输出的题目、解析、图片均经过服务端校验（长度、格式、图片域名与类型）；
- 回答会明确区分"科学事实 / 传统解释 / 地域差异"，并提供可核对的来源；
- 站内插画与游戏配图含 AI 生成内容，已在相应位置标注。

## 前端保护说明

本仓库中的线上构建做了以下处理（用于提高逆向与抄袭成本，浏览器必须执行代码，无法做到绝对不可破解）：

1. **JavaScript 混淆加密**：业务脚本经字符串数组加密（Base64）、控制流平坦化、十六进制标识符重命名，源码不可直接阅读；
2. **域名锁**：仅在 `xiao20060730qi-collab.github.io` 等授权域名下渲染；被镜像到其他域名时显示访问受限页，不渲染站点内容；
3. **防调试**：拦截 F12 / Ctrl+Shift+I/J/C/U/S/P，检测调试环境并提示；
4. **防复制**：禁用右键菜单、文本选中、复制 / 剪切、图片拖拽（表单输入不受影响）；
5. **版权水印**：右下角版权角标 + 全页平铺半透明水印，删除后自动恢复；
6. **防嵌套 / 打印限制**：检测 iframe 嵌套并跳出，打印时隐藏正文并输出版权提示。
